# Project Cleanup & Hygiene Report: AI-Based Adaptive Traffic Signal Optimization System

**Date:** October 28, 2026  
**Status:** Audit Completed — **PROPOSED DELETIONS ONLY (NO FILES DELETED AUTOMATICALLY)**  
**Safety Protocol:** In accordance with project instructions, all candidate files have been categorized, evaluated for operational impact, and are held pending explicit user confirmation before any deletion occurs.

---

## 1. Executive Summary

A comprehensive hygiene and storage inspection of the `traffic-signal-optimizer` repository was performed. The inspection identified three major categories of storage consumption and residual clutter:
1. **Accumulated Upload Artifacts:** Over 2,900 dynamically generated test images, annotated snapshots, and WAV files in `uploads/` totaling **~790.35 MB**.
2. **Redundant Dataset Zip Archive:** `ambulance_yolo.zip` (**408.5 MB**) whose contents are already completely unpacked and maintained under `data/emergency_yolo/`.
3. **Transient Debug Outputs & Evaluation Reports:** Scratch investigation scripts, single-run evaluation CSV/TXT dumps, cropped debug bounding box images, and YOLO training/validation run artifacts in `runs/` totaling **~8.7 MB**.

Virtual environments (`venv/`), Git version history (`.git/`), configuration files, core model weights, and essential datasets are **strictly excluded** from automatic deletion.
